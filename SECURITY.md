# Security policy

Please do not report vulnerabilities in public issues.

Send a private report through GitHub Security Advisories for this repository. Include the affected endpoint, impact, reproduction steps, and a minimal proof of concept. Do not access data that does not belong to you and do not degrade the production service.

Supported code is the latest release and the current `main` branch. Secrets, Telegram init data, VK launch parameters, refresh cookies, phone numbers, and complete request bodies must never be attached to a report.
